# Canonical Terminology

This monograph adopts the terminology defined by the
Behmanesh Structural Index (BSI).

Canonical terms include:

- Behmanesh Structural Index (BSI)
- Framework Fidelity
- Interpretation Drift
- Epistemic Integrity Gap (EIG)
- BIO
- Execution Pipeline
- Specification
- Execution Architecture
- Standard Operating Procedure (SOP)
- Guardrails

No alternative terminology should be introduced unless it is
formally defined within the BSI architecture.
