# Core Architectural Principles

1. User specification is the authoritative source of execution.

2. BSI governs execution rather than model cognition.

3. Architectural quality takes precedence over output quantity.

4. Framework Fidelity is an architectural property.

5. Execution evidence justifies architectural decisions.

6. Interpretation Drift is architectural evidence, not the architectural objective.

7. Professional analytical workflows require explicit execution governance.

8. Quality emerges from architectural discipline rather than prompt complexity.
